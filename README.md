# MyTurnTech

## Overview
Tech startup platform offering scholarships and educational opportunities for underprivileged students. Connect talented individuals with funding and mentorship.

## Tech Stack
- **Backend:** PHP, MySQL
- **Frontend:** JavaScript, HTML, CSS

## Key Features
- Scholarship application system
- Student profile management
- Donor/investor portal
- Application tracking
- Educational resource library
- Payment integration for scholarship distribution

## Getting Started
1. Clone the repo
2. Configure database in `.env`
3. Set up payment gateway credentials
4. Run migrations
5. Start the application
